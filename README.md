# Paso Note（提出用サンプル）

フラメンコのレッスン・課題・メモを整理するための、個人情報を含まない提出用サンプルです。

## この公開版について

- 実際の個人データは入っていません。
- Firebaseには接続していません。
- YouTubeの実URL・動画IDは含まれていません。
- 初回表示では、使い方が分かるように架空のサンプルデータを表示します。
- 入力した内容は、その人が使っているブラウザの `localStorage` にだけ保存されます。
- 他の利用者や、このリポジトリの所有者から入力内容を見ることはできません。

## 主な機能

- レッスン記録の追加・編集・削除
- 課題の追加・編集・削除・解決済み管理
- 全体メモ
- ヌメロによる絞り込み
- キーワード検索

## 自分用に使う場合

このリポジトリを Fork / Clone / Download ZIP して、自分用に編集して利用できます。
このサンプルのまま使う場合、入力内容は各ブラウザ内だけに保存されます。

## 技術

HTML / CSS / JavaScript

## プライバシー

提出用サンプルと本人用アプリは完全に分離しています。この公開リポジトリから本人用データへアクセスすることはできません。
